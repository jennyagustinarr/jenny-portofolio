# Jenny Agustina Rahman — Portfolio

Personal portfolio website for Jenny Agustina Rahman, Information Systems student at Institut Teknologi PLN.

## Pages
- `index.html` — profile summary and selected projects
- `about.html` — education, skills, work experience, and organizational experience
- `projects.html` — nine projects with category filters and direct links
- `achievements.html` — awards, publications, and credentials
- `contact.html` — contact details, CV, and email inquiry form

## Run locally
1. Extract the ZIP and open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

You can also use VS Code Live Server and open `index.html`.

## CV
All "CV" buttons open the Google Drive link: https://drive.google.com/file/d/1uXABG8Nl6SsYsSGBB4nn2kz0dtkqIqHo/view?usp=sharing

## Notes
- The contact form opens the visitor's default email application. It does not store or submit data to a backend.
- Project descriptions and achievement details are based on information supplied by the portfolio owner and the attached CV.
- No unprovided metrics, certifications, or project results have been added.


## Photo profile
Place your image at `assets/images/profile.jpg`. The About Me page displays a placeholder until that image is added.

## Theme modes
Use the navigation toggle to switch between Light Mode and Dark Mode. The selected theme is saved in the visitor's browser.

## Contact page
The Send an inquiry form has been removed. Direct email, phone, LinkedIn, GitHub, and CV links remain.
